# What this project values

Capped at 250 tokens: a ninth means arguing one of these eight out.

- **The record is the work.** A brief is the hypothesis before the code; a ledger is what
  executing it cost. Neither is rewritten afterwards to look right.
- **Derived beats declared.** Compute what git and the ledgers already know. A
  hand-maintained second copy goes stale.
- **One writer per file.** Conflicts are partitioned away, not merged. One ledger per
  brief, one declaration per contributor.
- **A skill guard is not a check.** Instructions to an agent are unenforced. Say
  so where you rely on one.
- **Tests prove the failure.** A guard that has never failed is unproven.
  Break it and watch it catch you.
- **Comment the why at the site.** Reasoning outlives the brief only beside the code.
- **Superseded is not deleted.** Old contracts and dropped drafts stay as
  tombstones; filed work cites them.
- **Report, don't gate.** Some tools observe, some enforce. Most observe.
