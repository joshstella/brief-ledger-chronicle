# Drafts

Unnumbered, uncommitted briefs live here. A draft is an idea that has been written down
but not yet filed — it has no serial, no identity, and no commitment.

Rules:
- Filenames must **not** begin with four digits (that format is reserved for filed briefs).
- A draft may stay here indefinitely. Deferring costs nothing.
- When ready to commit the work, run `/create-brief <filename>` from the repo root to
  file it into `docs/briefs/NNNN-slug/brief.md` with a serial assigned.
