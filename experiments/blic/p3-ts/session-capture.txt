BLIC prototype 3 (TypeScript + Ink) — one recorded session
==========================================================

How this was recorded, exactly:

  node dist/cli.js --capture=40 --peer-interval=7      segment A, with the peer stream
  node dist/cli.js --capture=8 --no-peers --filter=judged --select=2    segment B
  node dist/cli.js --capture=8 --no-peers --filter=all --select=1       segment C

  COLUMNS=130 LINES=40, output piped to a file, then ANSI escapes stripped with sed.

Two honest notes about the capture, before you read it:

  1. There is no TTY behind a pipe, so Ink cannot redraw in place. Each state change
     appends a whole fresh 40-row frame instead of repainting one. Segment A produced
     19 frames; four are reproduced below and the rest are identical except for the
     feed and the clock.
  2. For the same reason raw mode is unavailable, so no keystroke could be recorded.
     Segments B and C show what `f` reaches by starting there with a flag instead.
     The keyboard is real and is in src/ui/App.tsx; this file cannot prove it.

The colours are gone with the escapes. In a terminal the SYNTHETIC tag is black on
magenta, THEIRS is bold yellow, gate judgments are red, and this console's own lints
are magenta.
