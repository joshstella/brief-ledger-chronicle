BLIC prototype 2 — one session, as plain text
=============================================

Two recordings, because this machine has no pseudo-terminal: `script` cannot open one and the
program refuses to start on /dev/tty. So there is no recording of the real screen, and the two
things below are what honesty allows. REPORT.md section 6 says what that does and does not
prove.

  1. FRAMES — rendered by `blic -capture`, which drives the same model and the same view with
     the colors stripped. Every frame is the real layout at 124x40. Synthetic peer events are
     injected at the marked steps. Note that a synthetic event is still marked `SYNTH` with
     no color available, which is the point.

       ./blic -capture '4,peer:0,peer:1,tab,j,s,s,5,/,0,0,3,9' -width 124 -height 40

  2. PROOF OF LIFE — the tail of `blic -session`, which runs the actual Bubble Tea program
     against a scripted input stream with no terminal. The peer subprocess, the one-second
     ticker, the 20-second event reread and the key decoder all ran, and the program quit
     cleanly on `q`. The frame is a partial repaint, because the standard renderer repaints
     parts of the screen. It is here to show that the loop ran, not to be read as a layout.

       BLIC_PEER_INTERVAL=3 ./blic -session '4,j,tab,s' -hold 3s
